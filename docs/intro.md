# Customer-Driven AI CTI Project

This repository packages the published Customer-Driven AI CTI Project article series as a Docusaurus-ready documentation site.

The methodology is built for CTI engagements that must move beyond reporting into defensible customer outcomes: intelligence requirements, evidence handling, source validation, threat scenarios, hunt hypotheses, detection engineering, SOC handoff, executive reporting, and measurable improvement.

## Reading Order

1. [Workflow Quick Reference](/docs/workflow/full-workflow-quick-reference) for the end-to-end operational map.
2. [Part 1: Foundations](/docs/methodology/foundations) for analytic standards, governance, scoring, roles, and detection readiness.
3. [Part 2A: Phase-by-Phase Execution Guide](/docs/methodology/phase-by-phase-execution-guide) for Phase 0 through Phase 14 delivery execution.
4. [Part 2B: Reference Toolkit](/docs/methodology/reference-toolkit) for AI workflows, LLM task cards, quality gates, registers, and worked examples.
5. [Complete Template](/docs/methodology/complete-template) when you need the single-file source version.
6. [Infographics](/docs/infographics) for the imported visual assets from the published Medium articles.
